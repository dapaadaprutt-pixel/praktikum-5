
# Praktikum 5 - JavaScript Dasar

## Tujuan
Memahami dasar JavaScript dan manipulasi HTML.

## Langkah Praktikum
1. Membuat file index.html dan script.js.
2. Mempelajari output JavaScript.
3. Menggunakan alert dan prompt.
4. Membuat fungsi aritmatika.
5. Menggunakan if-else dan switch.
6. Membuat form cek bilangan genap atau ganjil.
7. Mengubah warna halaman.
8. Membuat daftar menu dan menghitung total.
9. Membuat kalkulator nilai mahasiswa.
10. Melakukan eksperimen validasi form dan manipulasi HTML.

## Cara Menjalankan
Buka file index.html menggunakan browser.

## Hasil Praktikum
Screenshot setiap latihan dan mini project dilampirkan sebagai bukti hasil praktikum.
